## Hosting and Server-Logfiles

This is a non-commercial website dedicated to a scientific project focusing on
the development of the complex plasma facility COMPACT.

This website is hosted by GitLab Inc. (via "GitLab Pages").
Upon visiting the site, the server automatically records information sent by
your browser and stores it in server log files (server access logs).
This data includes:

* IP address of the request
* date and time of access
* name and URL of the file accessed
* referring website (referrer URL)
* browser type and operating system

According to [GitLab's privacy policy](https://about.gitlab.com/privacy/)
subsection *GitLab Pages Data*, this data (server access logs) is kept for
7 days and then disposed of on a rolling basis.

This data is processed and controlled by
[GitLab Inc.](https://about.gitlab.com/company/).

For further details on how GitLab Inc. processes this data as the hosting
provider, please refer to
[GitLab's privacy policy](https://about.gitlab.com/privacy/).

## No Cookies or Tracking

This website does not collect any data.
This website does not use cookies, tracking tools, or analytics services.
